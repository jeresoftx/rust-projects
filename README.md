# Rust Projects

Curso-proyecto de Jeresoft Academy para construir sistemas reales en Rust, de
`grep` y `curl` a una versión educativa de Kafka. El objetivo no es clonar
productos de producción: es entender sus fronteras, invariantes, fallas y
trade-offs mediante implementaciones funcionales.

## Lugar En El Currículum

Este curso complementario convierte conocimientos de algoritmos, redes,
concurrencia, bases de datos, sistemas distribuidos y diseño de APIs en
proyectos integradores (RFC-0001 §10 y §14).

## Progresión

1. Herramientas de línea de comandos: `grep` y `curl`.
2. Servicios de red: servidor HTTP y load balancer.
3. Sistemas de estado: Redis y SQLite educativos.
4. Herramientas de plataforma: Git, Docker y NGINX reducidos.
5. Sistema distribuido integrador: Kafka educativo.

Sigue el índice en orden: `grep`, `curl`, servidor HTTP, balanceador, Redis,
