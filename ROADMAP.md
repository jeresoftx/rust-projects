# ROADMAP

`rust-projects` construye sistemas reales en orden de ambición, desde una
herramienta de línea de comandos hasta un log distribuido. La dirección no es
una carrera: cada proyecto solo avanza cuando su alcance, pruebas y límites son
claros (RFC-0001 §1 y §2).

El [GitHub Project #21](https://github.com/users/jeresoftx/projects/21) ya
contiene milestones, issues, dependencias y campos operativos. La fundación de
entrega está documentada; el siguiente bloque ejecutable es
`#2 → #3 → #4`: especificación, modelo y capítulo de `grep`.
