# Glosario

- **Backend:** destino interno al que un router o balanceador entrega trabajo.
- **Commit:** snapshot inmutable de un índice de contenido.
- **Offset:** posición de un mensaje dentro de una partición.
- **Partición:** secuencia ordenada independiente dentro de un log.
- **Prefijo:** inicio de una ruta que determina una regla de routing.
- **Snapshot:** copia lógica de estado que no cambia al modificar el estado actual.
- **TTL:** tiempo hasta que una clave deja de ser visible.
